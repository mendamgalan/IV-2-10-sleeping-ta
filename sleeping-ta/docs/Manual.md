# Sleeping Teaching Assistant — хэрэглэгчийн болон operational гарын авлага

IV-2-10 · F.CSM302 Үйлдлийн систем · Бие даалт 1 · хувилбар 1.1

## 1. Зорилго ба дэмжих орчин

Программ нь “Унтаж буй туслах багш” (Operating System Concepts, 7-р бүлгийн Project 2)
бодлогыг бодит POSIX thread, mutex, semaphore-оор загварчилна. TA болон оюутан бүр тусдаа
thread; Tkinter цонх нь C хөдөлгүүрийн төлөвийг шууд харуулж, цагийг удирдана.

| Зүйл | Шаардлага | Туршсан хувилбар |
|---|---|---|
| OS | Linux график орчинтой (Debian/Ubuntu) | Ubuntu 26.04.1 LTS, x86_64; GitHub Actions `ubuntu-latest` |
| Compiler | GCC, GNU Make | gcc 15.2.0, Make 4.4.1 |
| Runtime | Python 3, Tkinter (`python3-tk`) | Python 3.14.4, Tk 8.6.17 |
| Нэмэлт pip сан | Хэрэггүй | — |

Windows дээр WSL2 + WSLg-ээр ажиллах ёстой боловч бид туршаагүй. Native Windows, macOS-ийг дэмжихгүй.

## 3. Оролт ба тохиргоо

| Талбар | Утга | Хязгаар |
|---|---|---|
| Оюутан | Оюутны thread-ийн тоо | 1–40 бүхэл |
| Сандал | Хонгилын сандал (TA-ийн өрөөнийх тооцогдохгүй) | 0–20 бүхэл |
| Программчлах, с: min / max | Тусламжийн дараа дахин ирэх хүртэлх санамсаргүй хугацаа, оюутан тус бүрд | 0.1–600 с, 0.1-ийн алхамтай |
| Тусламж, с: min / max | Нэг удаагийн тусламжийн санамсаргүй хугацаа | 0.1–600 с, 0.1-ийн алхамтай |
| Seed | Санамсаргүй тооны эхлэл | 0–4294967295 |
| Чөлөөт горим | Асаавал оюутнууд нэг tick дотор зэрэг ажиллана (6-р хэсэг) | асаах / унтраах |

min = max бол хугацаа тогтмол. Талбарыг өөрчилсний дараа **↺ Reset** дарж хэрэглэнэ;
хэрэглэгдээгүй талбарын нэрний ард `*`, товчны мөрөнд “* Reset дарж хэрэглэнэ” гарна.
Буруу утга оруулбал аль талбар, ямар хязгаартай болохыг бичсэн цонх гарч, тухайн талбар
сонгогдоно; ажиллаж буй туршилт өөрчлөгдөхгүй.

## 4. Удирдлага

1. **Ажиллуулах** — загварын цаг бодит цагтай ижил хурдтай урагшилна.
2. **Ⅱ Түр зогсоох** — цаг болон бүх төлөв хөдөлгөөнгүй болно.
3. **→ Алхам +0.1с** — автомат горимыг зогсоож яг нэг tick (100 мс) гүйцэтгэнэ.
4. **↺ Reset** — хуучин thread-үүдийг зогсоож join хийгээд талбарын утгаар шинэ туршилт эхлүүлнэ.
5. **CSV хадгалах** — тухайн туршилтын бүх үйл явдлыг хадгална.
6. **Чөлөөт горим** — Reset дарсны дараа хэрэглэгдэнэ.
7. **Хурд ×1 / ×5 / ×20** — автомат горимын хурд; ажиллаж байхад сольж болно.

Цонх хаахад thread-үүд зогсож, түр журнал устна.

## 5. Дүрслэлийн тэмдэг ба өнгө

- **TA / ӨРӨӨ** — “Унтаж байна · Zzz” эсвэл “Sk-д тусалж байна”, үлдсэн хугацаа. Баруун дээд
  буланд горим: `seed` (давтагдах) эсвэл `чөлөөт`.
- **ХҮЛЭЭЛГИЙН ДАРААЛАЛ (FIFO) → TA** — сандал бүр нэг нүд, зүүнээс баруун тийш ирсэн
  дарааллаар; TA зүүн талын оюутныг дуудна. 10-аас олон сандал 2-р мөрөнд үргэлжилнэ.
- **ОЮУТНУУД** — оюутан бүр өнгөт тэмдэг, доор нь авсан тусламжийн тоо. Өнгө нь гарчгийн
  мөрөнд тайлбартай: цэнхэр — программчилж байна, шар — сандал дээр хүлээж байна,
  ногоон — тусламж авч байна.
- **Төлөвийн мөр** — хугацаа, ирэлт, дууссан тусламж, сандалгүй буцсан, хүлээлт / сандал,
  дундаж хүлээлт (сандал дээр суусан хугацааны дундаж), TA-ийн ачаалал (TA завгүй байсан хувь).
- **Лог** — сүүлийн 6 үйл явдал (`tick,event,student,waiting`).

## 6. Seed горим ба чөлөөт горим

- **Seed горим (өгөгдмөл).** Нэг tick-д эхлээд TA, дараа нь программчилж буй оюутнууд seed-ээр
  холисон дарааллаар нэг нэгээр ажиллана. Ижил seed, тохиргоо яг ижил үр дүн өгнө — туршилтыг
  давтах, алхамчилж тайлбарлахад тохиромжтой.
- **Чөлөөт горим.** Программчилж буй бүх оюутан нэг tick-д зэрэг ажиллаж, TA, сандал, mutex-ийн
  төлөө өрсөлдөнө; хэн түрүүлэхийг OS шийднэ. Үр дүн ажиллуулалт бүрт өөр байж болно, гэхдээ
  дүрэм (сандлын хязгаар, FIFO, баланс) хэвээр.

Хоёр горимд сандал дээрх оюутан `called[i]`, тусламж авч буй оюутан `done[i]` semaphore дээр
бодитоор блоклогдоно; сул TA `work` дээр унтана.

## 8. CSV

`tick,event,student,waiting`. Секунд = tick / 10. `student` 0 нь TA-ийн `sleep` үйл явдал.
`arrive` — ирэлт; `queue` — сандалд суух; `help_start`, `help_end` — тусламж; `full_return` —
сандалгүй буцах; `program` — тусламжийн дараа программчилж эхлэх. Бүтэн түүх түр файлд
хадгалагдаж, CSV хадгалахад бүтнээрээ хуулагдана. Экспорт амжилтгүй бол хуучин файл хэвээр,
амжилттай бол файлын эрх хадгалагдана. Reset эсвэл цонх хаахад түр түүх устдаг.

## 10. Operational шалгалт

```bash
gcc --version && python3 --version
make test                  # дэлгэцтэй орчинд
xvfb-run -a make test      # дэлгэцгүй серверт (sudo apt install xvfb xauth)
make tsan                  # ThreadSanitizer-тэй чөлөөт горимын stress тест
```

Хүлээгдэх үр дүн (`docs/test-results.txt`):

- `resource_failure` — thread/semaphore үүсгэх 3 алдааг өдөөж цэвэрлэгээг шалгана, exit 0.
- `stress` — чөлөөт горимд 15 000 tick, tick бүрт дүрэм шалгана: “invariants held”.
- Python unittest — 26 тест OK (хөдөлгүүр 8, regression 9, UI 9). Дэлгэцгүй үед UI-ийн 9 тест SKIP.
- `make tsan` — 5000 tick, data race 0.

Захын оролт: 0 сандал; 1 ба 40 оюутан; seed 0 ба 4294967295; хугацаа 0.1 ба 600 с.
Буруу оролт: оюутан 0/41/abc/3.5/хоосон, сандал -1/21, хугацаа 0/0.05/600.1/nan/inf,
min > max, seed -1/4294967296 — бүгд талбарын нэртэй мессежээр татгалзана.

Тайлангийн туршилтыг давтах: `python3 docs/experiments.py`. PDF-үүдийг дахин үүсгэх:
`make docs` (`python3-markdown`, LibreOffice Writer хэрэгтэй).

## 11. Мэдэгдэж буй хязгаарлалт

- Номын `sleep()`-ийн оронд 100 мс-ийн загварын цаг хэрэглэдэг; seed горимд оюутнууд нэг tick
  дотор ээлжлэн ажиллана. Зэрэг ажиллагааг чөлөөт горимоор шалгана.
- Сандалгүй буцсан оюутанд тодорхой хугацаанд заавал тусламж авах баталгаа байхгүй (номын
  шийдэлд ч байхгүй); тусламжийг tick бүрийн санамсаргүй дараалал тэнцүү хуваарилдаг.
- C API-г нэг удирдах thread дуудна; хугацаа, тоолуур `int` тул сар дамжин ажиллуулах зориулалтгүй.
- Дэлгэцийн шилжилт хооронд хөдөлгөөнт эффект байхгүй.
