# Хэрэглэгчийн болон operational заавар

## 1. Зорилго, орчин
TA ба оюутнуудын хамтын нөөц ашиглалтыг бодит POSIX thread-ээр загварчилна.
Linux, GCC, Make, Python 3, Tkinter шаардлагатай.
Суулгах ба эхлүүлэх команд:

```bash
sudo apt update
sudo apt install git build-essential python3 python3-tk
git clone https://github.com/mendamgalan/IV-2-10-sleeping-ta.git
cd IV-2-10-sleeping-ta/sleeping-ta
make
make run
```

Repository-ийн үндсэн хавтсаас ажиллуулах бол `make -C sleeping-ta run` хэрэглэнэ.
Тест: `make -C sleeping-ta test`. Программын хавтаснаас бол `make test`.


## 2. Оролт
| Талбар | Утга | Хязгаар |
|---|---|---|
| Оюутан | Оюутны thread-ийн тоо | 1–40 |
| Сандал | Зөвхөн хонгилын сандал | 0–20 |
| Ирэх min/max | Оюутан тус бүрийн программчлах санамсаргүй хугацаа | 0.1–600 секунд |
| Туслах min/max | Нэг удаагийн тусламжийн хугацаа | 0.1–600 секунд |
| Seed | Санамсаргүй тооны эхлэл | 0–4294967295 |

Хугацааны алхам 0.1 секунд, min ≤ max. Ижил min/max тогтмол хугацаа өгнө.
Ирэх завсар нь нийт урсгалын интервал биш: оюутан бүр тусдаа хугацаатай.
TA-д туслуулж байхдаа эсвэл хүлээхдээ дахин ирэлт үүсгэхгүй.

## 3. Удирдлага
1. Тохиргоог оруулаад **Тохиргоогоор reset** дарна.
2. **Ажиллуулах**: загварын цаг автоматаар урагшилна.
3. **Түр зогсоох**: хугацаа болон бүх загварын төлөв хөдөлгөөнгүй болно.
4. **Алхам +0.1с**: автомат горимыг зогсоож нэг tick гүйцэтгэнэ.
5. **Reset**: хуучин thread-үүдийг сэрээж join хийгээд шинэ туршилт үүсгэнэ.
6. **CSV хадгалах**: тухайн туршилтын үйл явдлын бүртгэл хадгална.
7. Цонх хаахад thread-үүдийг цэвэрлэж зогсооно.

TA-ийн өрөө: унтаж байгаа эсвэл тусалж байгаа оюутны дугаар, үлдсэн хугацаа.
Хонгил: зүүнээс баруун FIFO; 10-аас их сандалтай бол дараагийн мөрт үргэлжилнэ.
Цэнхэр оюутан программчилна, шар оюутан хүлээнэ, ногоон оюутан тусламж авна.
Доорх тоо нь тухайн оюутны дуусгасан тусламжийн тоо.

## 4. Туршиж үзэх жишээ
- Ердийн: 8 оюутан, 3 сандал, ирэх 1–4 с, туслах 1.5–3 с, seed 42.
  Дараалал, тусламж, буцах үйл явдлуудыг ажиглана.
- Ачаалал: 20 оюутан, 3 сандал, ирэх 0.1–0.2 с, туслах 3–4 с.
  Хүлээлт 3-аас хэтрэхгүй; сандалгүй буцсан тоо өснө.
- Захын: 1 оюутан, 0 сандал, ирэх 2–2 с, туслах 1–1 с.
  Шууд тусламж авна; сандалгүй буцсан тоо 0, TA үе үе унтана.

## 5. CSV
`tick,event,student,waiting`. Секунд = tick / 10. Student 0 нь TA-ийн sleep үйл явдал.
`arrive`: ирэлт; `queue`: сандалд суух; `help_start`: тусламж эхлэх;
`help_end`: дуусах; `full_return`: сандалгүй буцах; `program`: дахин программчлах.
Бүтэн түүх түр файлд хадгалагдана. UI зөвхөн сүүлийн 6 мөрийг харуулдаг тул
журнал өсөхөд бүх түүхийг tick бүр дахин уншихгүй. 256 KiB-ийн хуучин хязгаар арилсан.
CSV хадгалах үед түүхийг хэсэгчлэн хуулж, амжилттай болсон тохиолдолд зорьсон
файлыг солино. Алдаа гарвал хуучин экспорт хэвээр үлдэнэ.

Reset болон цонх хаахад түр түүх устдаг. Шаардлагатай CSV-ээ урьдчилан экспортлоно.
Дискний зай хүрэхгүй бол анхааруулга гарч, бүрэн бус түүхийн экспорт татгалзана.


## 6. Алдаа, хязгаарлалт
- `libta.so` олдохгүй: `make` ажиллуул.
- `No module named tkinter`: `sudo apt install python3-tk`.
- `no display`: Linux desktop terminal эсвэл WSLg дээр ажиллуул.
- Хугацаа/хязгаарын алдаа: min/max болон оролтын хүснэгтийг шалга.
- Өөрчлөлт харагдахгүй: reset дарж шинэ утгаа хэрэглэ.
- C API-г нэг удирдах thread-ээс дуудна; олон UI controller дэмжихгүй.
- Thread эсвэл semaphore үүсэхгүй бол үүссэн нөөцийг цэвэрлэж алдаа харуулна.
  Хөдөлгүүр зогссон үед Run ажиллахгүй; нөөцөө чөлөөлөөд Reset хийнэ.
- Түр файл үүсэхгүй бол хуучин туршилтыг хадгалж алдаа харуулна.
- Загварын цаг бодит ханын цагтай төгс таарахгүй. CPU ачаалал их үед дүрслэл удааширна.
- Дүрслэл алхамчилсан; шилжилт хооронд чимэглэлийн interpolation байхгүй.


## 7. Operational шалгалт

```bash
gcc --version
python3 --version
make test
```

14 хөдөлгүүр/интерфейсийн тест PASS болно. UI-ийн 4 тест график орчинд ажиллана;
дэлгэцгүй үед SKIP гэж ил тод тэмдэглэнэ. C тест нь TA thread, оюутны thread,
semaphore үүсгэх алдааг зориудаар өдөөж цэвэрлэлт болон дахин эхлүүлэлтийг шалгана.
Бүх тестийг дэлгэцгүй сервер дээр ажиллуулах:

```bash
sudo apt install xvfb
xvfb-run -a make test
```

Захын оролт: 0 сандал; 1 ба 40 оюутан; seed 0 ба 4294967295.
Буруу оролт: оюутан 0/41, сандал -1/21, хугацаа 0/600.1, min > max,
тоо биш утга. Model API-д том бүхэл тоо, bool, float, string мөн татгалзана.

Урт туршилт: 40 оюутан, 0 сандал, ирэх 0.1–0.1 с, туслах 1–1 с.
101 секунд хүртэл ажиллуулж экспортлоход сүүлийн tick 1010 байна;
хуучин хувилбар шиг 19 секунд орчимд журнал зогсох ёсгүй.

## 8. Гүйцэтгэлийн тайлбар

Нэг tick дотор TA-ийн үйлчилгээ, дараа нь оюутнуудын үйлдлийг ack semaphore-аар
дараалуулдаг. Thread бодит боловч чөлөөт зэрэгцээ scheduling турших горим биш.
Дүрслэл бодит C төлөвийг уншиж, UI хөдөлгүүрийн алхмыг удирдана.
Санах ойн snapshot болон экспорт API-г нэг удирдах thread-ээс дуудна.
Хугацаа, тоолуур C int тул олон сар тасралтгүй ажиллуулах зориулалтгүй.
